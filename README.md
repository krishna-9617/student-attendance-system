# Student Attendance System

A simple Python program to manage student attendance digitally.

## What it does:
- Add students and mark them present/absent
- View all attendance records
- Check attendance statistics
- Search for students
- Edit or delete records
- Filter by present/absent status
- Clear all data

## How to use:
1. Make sure Python is installed
2. Run: python attendance_system.py
3. Follow the menu options (1-10)

## Features:
1. Mark attendance
2. View records  
3. Get statistics
4. Clear all data
5. Search student
6. Edit attendance
7. Filter by status
8. Delete student
9. Count students
10. Exit program

## Benefits:
- Saves time compared to paper registers
- No calculation errors
- Easy to use
- Quick search and filtering

Note: Data is stored in memory and lost when program closes.
