# student-attendance-system
A simple Python program for student attendance management with marking, viewing and analysis features.

## What This Program Does
This program helps teachers to:
- Mark students as present or absent
- See all attendance records
- Check attendance percentage

## How to Use
1. Download the `attendance.py` file
2. Open terminal or command prompt
3. Type: `python attendance.py`
4. Follow the menu options

## Menu Options
- Press 1: Mark attendance
- Press 2: View all attendance
- Press 3: See attendance report
- Press 4: Exit program

## Requirements
- Python 3.x installed on your computer
- Basic knowledge of running Python programs

## How It Works
- Enter student names and mark them present or absent
- Program stores all data in memory
- You can view records anytime
- Get percentage of present students

## Notes
- Data is saved only during program run
- Close program to reset data
- Simple and easy to use
