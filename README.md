#​‍​‌‍​‍‌​‍​‌‍​‍‌ Student Attendance System



A digital system based on Python to manage student attendance in an efficient way.



## Overview



With this system, the process of recording attendance by using paper is abandoned, and a digital platform is introduced which not only simplifies the record-keeping process but also offers valuable insights into the patterns of student attendance. The platform, which is created for teachers and school management, provides a full range of tools that facilitate the effective handling of attendance data.



## Features



- Create student profiles and record daily attendance status



- Check attendance records which are systematized



- Compute attendance percentages and likewise expressions



- Find records of single students



- Modify current attendance entries



- Remove student records



- Delete with confirmation all data



- Generate attendance reports



- Extract data in a CSV file



- Multiple classes are supported



## Requirements



- Python version 3.x or later



- No need for any external dependencies



## Installation



1. Get the attendance_system.py file



2. Make sure Python is on your machine



3. Running the program via a command line



## Usage



Run the program ​‍​‌‍​‍‌​‍​‌‍​‍‌with:

You​‍​‌‍​‍‌​‍​‌‍​‍‌ can access all features by using numbers 1–8 to move through the easy-to-understand menu system.



## Menu Options



1. **Mark Attendance** - Register the daily presence and absence of students



2. **View Records** - Open and read all attendance documents



3. **Get Statistics** - Create summaries and percentages of attendance



4. **Clear All Data** - System resetting with user verification



5. **Search Student** - Locate quickly the records of a single student



6. **Edit Attendance** - Change the attendance already entered



7. **Delete Student** - Get rid of a student record from the system



8. **Exit Program** - Put the program to rest nicely



## Benefits



The digital system is loaded with great features that make traditional methods look outdated. It is highly effective in saving the time that is usually wasted on manual writing of records and also, it completely eliminates calculation errors from paper-based systems. The well thought out interface is self-explanatory and requires a bare minimum of training, while the efficient search and filtering features empower users to locate any needed data within seconds.



Being portable, it can be used on any platform, and its scalable design will attract more users in the future. Educators will be glad to note that the system brings about less paper use and thus, they get more time to concentrate on their core task, which is teaching.



## Technical Details



The whole project is done in Python 3, which makes it very reliable and cross-platform compatible. For the best speed during the on-going session, it utilizes volatile memory.



The application is constructed solely from Python's standard library components, thus there is no need for additional library installations, making it very convenient to deploy.



The software is built to work on Windows, macOS, and Linux gadgets and does not require powerful and newest machines to function smoothly. The source code is designed to be less prone to bugs, and the author(s) have adhered to Python good coding standards to make the program more stable and easier to maintain further.



## Sample Interaction



First, turn on the software and decide to do the attendance carrying out task. Write down the student's full names and what happened using easy-to-understand codes (P for present, A for absent). The system keeps confirming each operation without delay.



The user chooses the viewing documents function to get access to all records relating to attendance kept in an understandable way. They then utilize the statistics option to come up with detailed reports illustrating attendance history and percentages for their further directed decision-making.



## Important Note



The version available is that which saves the information in the local memory of the machine being used while the program runs. The files with records of attendance are only for the present session and thus, will be gone when the software is shut down. Entities that want storage solutions should take exporting regularly as their means or think about database integration.
